# last

Returns the last element of an array. Returns `null` if the array is empty.

#### Syntax

```
last(array)
```

or chained:

```
<array>.last()
```

#### Arguments

* **array** (`array`, optional when chained) - The array to get the last element from.

#### Examples

```
last([1, 2, 3])
// 3
```

```
["a", "b", "c"].last()
// "c"
```

```
last([])
// null
```
