# toLower

Converts a string to lowercase.

#### Syntax

```
toLower(input)
```

or chained:

```
<string>.toLower()
```

#### Arguments

* **input** (`string`, optional when chained) - The string to convert.

#### Examples

```
toLower("HELLO")
// "hello"
```

```
"HELLO WORLD".toLower()
// "hello world"
```
