# floor

Returns the largest integer less than or equal to the input. If the input is already an integer, it is returned as-is.

#### Syntax

```
floor(value)
```

or chained:

```
<number>.floor()
```

#### Arguments

* **value** (`int | float`, optional when chained) - The number to floor.

#### Examples

```
floor(3.7)
// 3
```

```
floor(-2.3)
// -3
```

```
floor(5)
// 5
```
