# first

Returns the first element of an array. Returns `null` if the array is empty.

#### Syntax

```
first(array)
```

or chained:

```
<array>.first()
```

#### Arguments

* **array** (`array`, optional when chained) - The array to get the first element from.

#### Examples

```
first([1, 2, 3])
// 1
```

```
["a", "b", "c"].first()
// "a"
```

```
first([])
// null
```
