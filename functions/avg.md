# avg

Returns the average of the given numbers. Always returns a float value.

#### Syntax

```
avg(value1, value2, ...)
```

#### Arguments

* **values** (`int | float`) - Two or more numeric values to average.

#### Examples

```
avg(1, 2, 3)
// 2.0
```

```
avg(10, 20)
// 15.0
```

```
avg(1.5, 2.5, 3.0)
// 2.333333...
```
