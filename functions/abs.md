# abs

Returns the absolute value of a number. Works with both integers and floats.

#### Syntax

```
abs(value)
```

or chained:

```
<number>.abs()
```

#### Arguments

* **value** (`int | float`, optional when chained) - The number to get the absolute value of.

#### Examples

```
abs(-5)
// 5
```

```
abs(-3.14)
// 3.14
```

```
abs(10)
// 10
```
