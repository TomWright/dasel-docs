# toUpper

Converts a string to uppercase.

#### Syntax

```
toUpper(input)
```

or chained:

```
<string>.toUpper()
```

#### Arguments

* **input** (`string`, optional when chained) - The string to convert.

#### Examples

```
toUpper("hello")
// "HELLO"
```

```
"hello world".toUpper()
// "HELLO WORLD"
```
